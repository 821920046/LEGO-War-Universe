自主想象力：一句描述构思 N 部电影，前端只留最好的那一部

前十二轮修的都是「一部片子的质量」。本轮用户指出的是另一个维度 —— 换任何一句描述，拿到的都是同一部电影。

一句话结论：planFilm 的 seed 只由 主题｜镜头数 决定，视角 / 叙事重心 / 基调三个维度根本没有参数化——它们是常量。 实测 408 镜 → 332 个不同骨架，34.6% 的镜头与其它片子共用同一个句子骨架。 同时环境选型还是「正则筛子集 → 排序 → 取第一个」，题材词与环境名对不上时排序全 0， 退化成资产库数组顺序：「黎明时分强渡冰河」与「月球表面争夺登月舱」双双拿到中东沙漠 —— 而库里明明有 ENV-507 泛滥的沼泽地 / ENV-503 渡河点 / ENV-703 月面基地，只是选不到。

「多方案」不是把一部片换四次皮。首个版本生成 4 个方案后才发现 其中两部骨架重合 88%，只能靠扣分事后打折。最终做法是候选池放大 3 倍、 打分排序后贪心挑选，与已入选方案骨架重合 > 45% 就跳过； 判据也一并收紧：【代号】人名 整段归一成一个 P —— 不归一的话「只换了人名」的两部片会被算成完全不同，「重合率 0%」这个数字是假的。

腿分值为什么这么定
专名（最长公共子串 ≥3）len × 2.5，封顶 8第一版按二元词切，库尔斯克 → 库尔｜尔斯｜斯克，26 个内置题材当场劣化 10 个
字面二元词（只在 nameZh/kw 上数）4 / 命中正文里 sky / ocean 到处都是，会白送分
概念桥3 / 命中用户说「强渡」，库里写「渡河点」；只收概念不收题材
场地域+8 / −8（第一轮只软罚 −3）只从人写字段推；从正文推会把「中东沙漠」因 clear sky 判成 air
时代亲和+5 软加分硬过滤会把更合适的环境一票否决
原型亲和+10（第一轮权重为 0）否则「港口炸潜艇」会被原型亲和一路送进潜艇舱

三道闸：题材直接证据（≥6 就定）→ 原型亲和（≥8 就定）→ 时代扩容； 同级排序为 分数 → 具体度 → id 散列 —— 具体度必须是第二键： 「穿越沼泽」里沼泽地与争夺中的桥梁同得 17 分，直接跳散列会把沼泽片送到桥上。

⑥ 本轮自己引入并修掉的三个缺陷

① diversify() 读了不存在的字段
- const skelOf = c => (c?.film?.shots || [])
-     .map(s => skeletonOf(s.action));
+ const skelOf = c => (c?.film?.plan?.shots || [])
+     .map(s => skeletonOf(s.action));

`film` 是 planFilm 的返回值（{ intent, plan, … }），
镜头在 `film.plan.shots` 里。
读错 → curS 恒为空 → `if (!curS.length) continue`
→ 整个去重加罚静默跳过。
「4 个方案里 3 个是同一部片」一次也没被抓到过。
② 时代池与校验器不是同一把尺子
- const eraEnvs = allEnvs.filter(a => a.series === intent.era);
+ const eraEnvs = allEnvs.filter(a => isEraCompatible(a.series, intent.era));

planner 用「精确相等」，validateShotSpec 用
isEraCompatible（Modern ↔ Modern High-Tech 互通）。
界面默认示例判为 Modern 后，唯一的
ENV-640 现代高科技地下指挥掩体连被打分的机会都没有：
它在全库拿 44 分，时代池里最好的「暴风雪山口」
只有 9 分（一个「暴风」二元词）却过线当选。
③ 探针自己也会骗人
- toneHit(a, tone, 'colorGrade')   // 键不存在 → 恒 false
+ toneHit(a, tone, 'grade')

统计基调覆盖率时把 kind 写成了 'colorGrade'，
而 tone-prefs.js 的键是 'grade'，
于是得出「调色基调覆盖率 0/5」的假结论。

探针写错比不写更危险 —— 它会让人以为
修好了、或者修坏了。
④ 战略域被当成与地面互斥
- const domLock = domain && domain !== 'ground';
+ const domLock = domain && domain !== 'ground'
+                && domain !== 'strategic';

导弹阵地就建在地面上，战略域与地面域是
上下位不是并列互斥。此前的互斥把「中东沙漠」
当成「地面专属景物」滤掉，
海湾战争的防空阵地被搬进空军基地，
连带把沙漠暖调《黑鹰坠落》换成二战冷调《兄弟连》。

⑦ 遗留风险（如实记录）

风险现状
基调仍是最弱的一维它只做同分决胜（+6），压不过「域 + 功能 + 景别」的物理分；实测 4 种基调在 8 镜片里只改出 1 处机位差异。让它参与池内筛选会与光质 / 场景 / 时代的硬约束打架，本轮选择先不动。
少数题材压不到 45% 以下斯大林格勒狙击手题材的节拍文本池本身窄，8 镜里有 4 镜只能共用骨架，换种子重试也只能降到 50%（已从 75% 降下来）。
候选方案不落库刷新页面后备选消失，需要重新点一次生成（约 0.4 – 1.0 秒）。生成是确定性的，结果不变。
边界没有变本轮验证的是「多部片子的差异度与自洽度」，这些 prompt 依旧一次也没有跑过 Veo 3 / Flow。「自洽」与「有效」之间的那道墙，第十三轮依旧没有推倒。
