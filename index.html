🎬 Google Flow 8 秒镜头规范（速查）
• 一个镜头 = 一个核心动作；不要把多件大事塞进 8 秒。
• 每个镜头引用同一套资产（Style + 角色 + 载具 + 环境），保证跨镜头一致性。
• 镜头衔接：勾选「动作接力」让下一镜头从上一动作的结果开始。
• 一致性锁定：对反复出场的角色/英雄载具，建议在 Flow 里用 Ingredients 上传参考图（见生成结果下方提示）。
• 提示词结构：镜头运动 → 主体 → 动作 → 场景 → 灯光 → 风格 → 色彩 → 音频（→ 台词），约 100~150 词。
• 正向描述，避免 now/then/continues 等时间词；英文效果最佳；台词用引号且简短。
