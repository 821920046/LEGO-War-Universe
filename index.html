🎬 Google Flow 8 秒镜头规范（速查）

• 一个镜头 = 一个核心动作；不要把多件大事塞进 8 秒。
• 每个镜头引用同一套资产（风格 + 角色 + 载具 + 环境），保证跳镜头一致性。
• 镜头衔接：勾选「动作接力」让下一镜头从上一动作的结果开始。
• 一致性锁定：对反复出场的角色/英雄载具，建议在 Flow 里用 Ingredients 上传参考图。
• 提示词结构：运镜 → 主体 → 动作 → 场景 → 灯光 → 风格 → 色彩 → 音频（→ 台词），约 100~150 词。
• 正向描述，避免 now/then/continues 等时间词；英文效果最佳；台词用引号且简短。
• 实体一切皆积木，天气/水体/硝烟/火焰/爆炸用真实物理质感 —— 这是本项目的混合真实感准则。

如何启用 AI 导演（多模型自动故障转移）
1. 进入 Cloudflare Pages 项目 → Settings → Environment variables。
2. 添加下面任意一个或多个密钥（类型选 Secret）：GEMINI_API_KEY、GROQ_API_KEY、OPENROUTER_API_KEY（这三家均有永久免费额度，无需绑卡）。
3. 点 Redeploy 重新部署（环境变量必须重部署才生效）。
4. 回到本页点「重新检测」，状态变为绿色即可。
5. 想自定义顺序可加 MODELS，例如 gemini:gemini-2.0-flash, groq:llama-3.3-70b-versatile, openrouter:deepseek/deepseek-chat-v3-0324:free；一个模型失败会自动换下一个，并按请求轮询分摊额度。
6. 全免费方案（推荐）：只需设置 MODELS = free，即启用内置的 11 档免费模型链，全部来自 Gemini、Groq、OpenRouter 三个免费账号：Gemini 2.0 Flash / Flash-Lite / 1.5 Flash → Groq Llama 3.3 70B / 3.1 8B / Gemma2 9B → OpenRouter 的 DeepSeek V3、Gemini 2.0 Flash Exp、Llama 3.3 70B、Qwen2.5 72B、Mistral Small（均为 :free 版）。没配的密钥会自动跳过，配 1 个就能跑，配 3 个最抗限流，全程零费用。
7. 体检（排错神器）：部署后在浏览器直接打开 你的域名/api/compose?probe=1，它会逐个真实调用链上的每个模型，返回 ok:true/false 与失败原因（密钥无效 / 限流 429 / 模型名不存在 / 超时），一眼看出到底是哪一家出了问题。
8. 如遇 502：说明 AI 函数被平台中断。V4.3 已内置 24 秒总预算 + 最多 4 次故障转移，正常不会再出现；若仍出现可加 DEADLINE_MS=18000、MAX_ATTEMPTS=3 进一步收紧。

💾 数据与备份

所有影片与分镜保存在本浏览器的本地存储里，不会上传。长期使用建议每周导出一次工程 .json 存档；换电脑或换浏览器时导入即可继续。

⌨️ 快捷操作

Ctrl+Enter（主题框内）生成整片分镜  ·  Ctrl+K 跳到主题框  ·  每个镜头右侧的「已生成」勾选框可记录你在 Flow 里的渲染进度，进度条与顶部统计会同步。
