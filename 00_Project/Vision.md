# Vision — 项目愿景

## 一句话定位

**LEGO War Universe（LWU）** 是一个用 Google Flow (Veo 3) 制作的乐高战争电影宇宙，采用电影工业的资产管理方式，实现长片级别的一致性与可持续生产。

## 为什么先做 Bible，而不是先写 Prompt

单个漂亮的 Prompt 只能生成一个孤立的 8 秒镜头。当你要拍几十、几百个镜头拼成一部电影时，真正的难题不是「写得好」，而是：

- 同一个士兵在第 3 镜和第 87 镜长得一样吗？
- 同一辆坦克的比例、涂装、磨损一致吗？
- 整部片的光线、色调、风格统一吗？

电影公司（迪士尼、皮克斯、ILM、Weta）解决这个问题的方式不是「每次重画」，而是**建立资产库**：角色、载具、场景一旦确定，全片复用，逐字不改。本项目把这套方法搬到 AI 视频生成。

## 系列规划（共用同一套资产）

本体系一次建成，可持续产出以下题材，全部复用同一资产库与模板：

| 系列 | 战役 |
|---|---|
| 现代战争 | 海湾战争、伊拉克战争、阿富汗战争 |
| 二战系列 | 诺曼底登陆、中途岛海战、斯大林格勒、柏林战役 |
| 海战系列 | 航母大战、现代海战 |
| 冷战系列 | 冷战对峙、代理人战争 |

扩展新战役时**只需在 `assets.json` 增加资产**（新载具/新角色/新环境），世界规范、镜头语言、Prompt 模板全部不变。

## 成功标准

1. 任何一个 8 秒镜头都能由资产直接组装生成。
2. 100 个镜头拼接后，人物、装备、风格仍保持一致。
3. 新增任何战争题材只需增加资产，不需要重写规范。
4. 非专业用户也能通过组装器在 1 分钟内产出合格的 Flow Prompt。

## 版本路线

- **V1.0** 世界观与各类 Bible（设定）。
- **V1.1** Asset Pipeline（资产管线分层）。
- **V2.0** ⭐ 本版本：机器可读资产库 `assets.json` + Prompt Composer 自动组装引擎 + 完整制作 SOP。
