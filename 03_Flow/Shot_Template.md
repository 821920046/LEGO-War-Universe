# Shot Template — 单镜头模板

每个镜头在分镜表中的标准字段：

```
Shot ID:     S0xx
Movie:       Gulf War
Title:       （一句话核心动作）
Subjects:    CHR-00x, VEH-00x （引用资产编号）
Environment: ENV-00x
Camera:      CAM-00x
Lighting:    LGT-00x
Color:       CLR-00x
Motion:      （动作库条目）
FX:          FX-00x （可选）
Audio:       AUD-00x （可多选）
Dialogue:    （可选，引号内，短）
Continuation:是 / 否（是否与上一镜衔接）
Duration:    8s
```

## 填写建议

- Title 只写一个核心动作。
- Subjects 尽量≤ 2 个主体，避免画面拥挤、出现多余对象。
- 镜头编号递增（S001、S002…），组装器加入清单时会自动递增。
