# 04_Movies — 系列影片

每部影片一个子文件夹，包含 `Shot_List.md`（分镜表）与 `Timeline.md`（时间轴）。所有影片共享 `01_Bible/` 与 `02_Assets/assets.json` 的同一套资产。

## 当前影片

- **Gulf_War/** — 海湾战争（已完成 90 秒示范分镜 S001–S012）。
