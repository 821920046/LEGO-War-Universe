# Prompt Composer — 提示词组装器说明书

组装器是本项目的核心工具，实现为根目录 `index.html`（纯静态网页，无需后端，可部署到 Cloudflare Pages）。

## 它做什么

把 `02_Assets/assets.json` 里的资产（风格/角色/载具/环境/镜头/灯光/色彩/动作/FX/音频/负面）自动拼成一段符合 Flow 规范、可直接粘贴的英文 Prompt。

## 界面功能

- **镜头编号 Shot ID**：自动递增（S001、S002…），也可手动改。
- **影片 Movie**：归属哪部片。
- **标题 / 动作**：一句话核心动作。
- **主体选择**：角色 + 载具多选芯片。
- **环境 / 镜头 / 灯光 / 色调**：下拉选择。
- **动作**：根据所选主体类别自动筛选可用动作。
- **FX / 音频**：多选芯片。
- **画幅比例**：16:9 / 9:16。
- **变体数（1/3）**：一次生成 1 或 3 个微变体（方便在 Flow 里多抽。
- **对白 Dialogue**：可选，自动加引号。
- **Continuation 勾选**：与上一镜头动作衔接。
- **Negative 勾选**：是否附加统一负面约束（默认开）。

## 镜头清单（Shot List）

- 生成后可「加入镜头清单」，数据存在浏览器 localStorage（键：`lwu_shotlist_v1`）。
- 支持复制单镜、导出全部为 `.txt`、清空。
- 刷新页面不丢失（本地存储）。

## 快捷键

- **Ctrl / Cmd + Enter**：生成 Prompt。

## 如何扩充资产

1. 编辑 `02_Assets/assets.json`，按命名规范新增条目。
2. 重新把 assets.json 内容嵌入 `index.html` 的 `<script id="lwu-data">` 标签（部署时也可改为 fetch 加载）。
3. 刷新页面，新资产自动出现在选项里。

> 注：当前 `index.html` 已内嵌一份 assets.json 快照，双击即可离线使用；若后续修改了 JSON，记得同步重嵌。
