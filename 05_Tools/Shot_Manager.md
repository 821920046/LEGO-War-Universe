# Shot Manager — 镜头管理

镜头不再叫「第一段/第二段」，而是用 S 编号，便于修改与重拍。

## 镜头状态

| 状态 | 含义 |
|---|---|
| Planned | 已列入分镜，未生成 |
| Prompt Ready | 组装器已生成 Prompt |
| Generated | Flow 已生成视频 |
| Approved | 审核通过，入片 |
| Reshoot | 需重拍 |

## 工作流

1. 在组装器里逐个生成镜头 Prompt，「加入镜头清单」。
2. 按 S 编号去 Flow 生成，回填状态。
3. 需要重拍：直接说「重做 S014」——在组装器里把 Shot ID 改回 S014，调整参数，重新生成，不影响其他镜头。

## 组装器内的镜头清单

- 镜头清单存在浏览器 localStorage（键：`lwu_shotlist_v1`），刷新不丢。
- 可导出全部为 `.txt`，归档到对应 `04_Movies/<片名>/` 下。
- 建议定期把清单导出备份。

## 命名建议

- 镜头文件名：`S001_carrier_launch.mp4`（编号 + 英文短描述）。
- 变体：`S001_v1 / S001_v2 / S001_v3`。
