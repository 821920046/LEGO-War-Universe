# QA Checklist — 质量检查清单

每生成一个镜头，对照本清单验收。

## 一致性

- [ ] 角色使用统一 CHR 编号，描述逐字复用
- [ ] 载具使用统一 VEH/AIR/SHP 编号，标记/比例/磨损一致
- [ ] 风格块 STYLE-LWU 在 Prompt 开头
- [ ] 负面约束 NEG-LWU 在 Prompt 结尾
- [ ] 同一段落内 ENV + LGT + CLR 一致

## 镜头自身

- [ ] 只有一个核心动作，能在 8 秒内完成
- [ ] 运镜与主体动作分开描述
- [ ] Prompt 为英文，约 100–150 词
- [ ] 正文无时间/顺序词（now/then/continues）
- [ ] 画幅比例、720p、24fps 已声明

## 画面缺陷（生成后检查）

- [ ] 无多余角色/重复载具
- [ ] 无融化/变形积木，无卡通夸张
- [ ] 比例正确，无悬浮物体
- [ ] 军事标记正确
- [ ] 无字幕/水印/logo
- [ ] 色调与前后镜头一致

## 音频

- [ ] 主体音效正确（引擎/爆炸/无线电）
- [ ] 对白（如有）能在 8 秒内说完
- [ ] 配乐与段落一致

## 未通过时

参考 `00_Project/Flow_Best_Practices.md` 的「生成失败时的修正策略」逐项调整，只重拍当前 S 镜头。
