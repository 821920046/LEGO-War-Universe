# Timeline System — 时间轴系统

Google Flow 天然按 8 秒块工作，整片 = 若干 8 秒镜头顺序拼接。

## 基本规则

- 1 个 S 编号 = 8 秒。
- 时间码 = (镜头序号 - 1) × 8 秒。

| 镜头 | 起始时间 |
|---|---|
| S001 | 00:00 |
| S002 | 00:08 |
| S003 | 00:16 |
| S004 | 00:24 |
| … | … |

## 片长估算

| 片长 | 镜头数 |
|---|---|
| 8 秒预告 | 1 |
| 90 秒短片 | ≈ 12 |
| 3 分钟 | ≈ 23 |
| 10 分钟 | ≈ 75 |

## 节奏建议（如何用 8 秒镜头组成长片）

1. **开场（约 10%）**：大景/无人机镜头建立世界（CAM-001）。
2. **铺垫（约 20%）**：人物/装备出场，中景。
3. **高潮（约 50%）**：战斗、发射、爆炸，快切 + 特写（CAM-004）。
4. **回落（约 20%）**：收尾、宁静镜头，英雄亩像（CAM-008）。

## 延长方式

- 在段落内插入新镜头，S 编号顺延（如在 S006 后插 S006b 或重排为 S007+）。
- 修改单镜只影响该 S，不影响整片。
